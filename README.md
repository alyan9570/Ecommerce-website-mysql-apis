# 🛒 E-commerce Backend API (MySQL)

A backend API for an e-commerce system built using Node.js, Express, and MySQL.  
This project handles user authentication, product management, cart functionality, and order processing.

---

## 🚀 Technologies Used
- Node.js  
- Express.js  
- MySQL  
- JWT (JSON Web Token)  
- MySQL2  
- REST API  
- Postman (API Testing)

---

## ✨ Features
- 🔐 User Authentication (Signup/Login using JWT)  
- 🛍️ Product Management (Create, Read, Update, Delete)  
- 🛒 Cart System (Add, Update, Remove items)  
- 📦 Order Management (Place and view orders)  
- 🔑 Protected Routes (Only authenticated users can access certain APIs)  
- 📊 Structured relational database (MySQL)

---

## 🗄️ Database Design
Main tables used in this project:
- Users  
- Products  
- Cart  
- Orders  
- Order_Items  

Relationships:
- One user can have multiple orders  
- One order can have multiple products  
- Cart is linked with users and products  

---

## ⚙️ Project Process
1. Designed relational database schema in MySQL  
2. Created tables and defined relationships  
3. Built REST APIs for users, products, cart, and orders  
4. Implemented authentication using JWT  
5. Connected Node.js with MySQL database  
6. Handled real-world logic (cart → order conversion)  
7. Tested APIs using Postman
